# 💣 지뢰찾기

브라우저에서 즐기는 클래식 지뢰찾기입니다. 초급·중급·고급 보드, 첫 클릭 안전, 깃발과 물음표 표시, 숫자 칸 양쪽 클릭을 지원합니다. HTML, CSS, Vanilla JavaScript로 구성되어 별도 설치나 빌드 과정 없이 실행할 수 있습니다. 실습 진행 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

안전한 칸을 모두 열면 승리합니다. 숫자는 주변 8칸에 있는 지뢰 수를 나타냅니다. 빈 칸은 주변 안전한 칸까지 자동으로 열리며, 지뢰를 열면 패배합니다.

## 어떻게 만들었나요

PRD에 정의한 동작을 구현 계획으로 정리한 뒤, HTML·CSS·Vanilla JavaScript 파일로 분리해 구현했습니다.

## freeform 버전과 비교했을 때

현재 저장소에는 PRD 기반 버전만 구현되어 있습니다. freeform 버전과 비교하거나 최종 버전을 선택하려면 두 브랜치의 구현을 함께 확인해야 합니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 됩니다. 인터넷 연결이나 패키지 설치가 필요하지 않습니다.

## 커스터마이징한 부분

난이도별 보드, 첫 클릭 주변 안전, 깃발·물음표 순환, 양쪽 클릭, Flood Fill 확장, 타이머, 재시작 및 승패별 상태 표시를 구현했습니다. 사용자 지정 보드, 기록 저장, 모바일 전용 터치 제스처, 사운드는 포함하지 않았습니다.
